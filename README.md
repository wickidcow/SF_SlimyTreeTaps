## What is SF_SlimyTreeTaps?

SlimyTreeTaps adds tree taps for collecting resin from supported logs. Resin can be processed into rubber and used as an alternative route toward plastic production. The maintained fork also supports modern vanilla resin behavior where applicable and preserves the addon's amber and magic-themed content.

Features include:

- tree taps and resin collection;
- rubber production;
- alternative plastic production;
- modern vanilla resin integration;
- amber and related magic-themed items;
- English-first maintained source and bundled resources.

## Download and build

Release JARs use the maintained Slimefun-addon naming convention:

`SF_SlimyTreeTaps1.0.2.jar`

The project builds with **Java 25** while targeting **Java 21 bytecode**. The production compatibility baseline is **Slimefun Legacy 4.1.48 on Paper 26.2**. Development builds are available from GitHub Actions and versioned release JARs are published on the Releases page.

---
## Compatibility

Primary target: **Slimefun Legacy**.

Compatibility is also validated against Slimefun United, SlimefunGuguProject/Slimefun4, and original Slimefun4-compatible APIs. Paper is the primary server family; Purpur, Folia and Leaf are compatibility targets.

The maintained fork avoids external Slimefun utility-library dependencies and keeps cross-fork support on the shared Slimefun addon API wherever practical.
